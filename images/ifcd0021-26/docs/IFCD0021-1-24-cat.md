# IFCD0021-24

**Resum del Curs IFCD0021-24 Java FullStack (2024)**

> El curs IFCD0021-24 és un programa intensiu de **11 setmanes** de Java FullStack que es desenvolupa des de principis de setembre fins a mitjans de novembre de 2024.

> Porta els estudiants des dels conceptes fonamentals de Java fins a una aplicació full-stack moderna completa, utilitzant **Spring Boot** al backend i **Vaadin** (amb components React) al frontend.

> El curs segueix una metodologia àgil **Scrum** amb sprints, sessions de planificació, retrospectives i un fort èmfasi en el desenvolupament pràctic i iteratiu.

## Estructura i Metodologia del Curs

Organitzat per mesos i sprints, el programa posa èmfasi en la planificació, el **Domain-Driven Design (DDD)**, l’arquitectura i les bones pràctiques de codi net.

Els estudiants treballen intensament en un únic projecte en evolució — **Restaurant** (després RestaurantManager / RestaurantVaadin) — que progressa des d’una aplicació de consola fins a una aplicació web professional.

Els principis clau que es reforcen inclouen:

- Baix acoblament (low coupling)
- Modelatge UML
- Desenvolupament guiat per proves (TDD)
- Presa de decisions reflexiva entre “pensar i després codificar” versus “codificar i després pensar”
- Responsabilitat de l’aprenentatge (Pareto, lateralització, mindset)

### Setembre 2024: Fonaments i Aplicació de Consola

El curs comença amb una sessió de presentació que cobreix la mentalitat del desenvolupador, Scrum/Agile, i el que el curs **és** i **no és**.

Els estudiants aprenen:

- Fluxos de treball amb Git/GitHub
- Configuració de projectes Maven
- UML (incloent Mermaid)
- Conceptes bàsics de Java SE (static vs no-static, àmbit, classes i objectes, HashMap)

El focus principal és la construcció de l’aplicació de consola **Restaurant**:

- Entitats (Order, Table, Menu…)
- Patró Repository / Manager (HashMap)
- Lògica de negoci (createOrder, calculateTotalPayment…)
- Controladors i flux de dades
- Introducció a JUnit + Mockito
- DDD i desacoblament

Aquesta fase estableix una base sòlida en disseny orientat a objectes i lògica de negoci.

### Octubre 2024: Desenvolupament del Backend amb Spring Boot + Vaadin

El projecte migra a **Spring Boot** (RestaurantVaadin / RestaurantManager).

Els estudiants dominen:

- Configuració del projecte amb JPA, base de dades H2 i dependències Maven
- Relacions entre entitats i anotacions JPA
- Repositories, Services i Controllers
- Funcionalitats avançades de JPA (herència, @Transactional, consultes…)
- Introducció a Vaadin com a capa de presentació
- Arquitectura per capes i injecció de dependències
- Proves i bones pràctiques

Altres temes: time management, mindset (growth vs fixed), DevOps bàsic (snapshots, documentació).

### Novembre 2024: Frontend, Integració Full-Stack i Temes Avançats

La fase final se centra en:

- Aprofundiment en JPA (herència, estratègies de persistència, paginació)
- Integració completa Spring Boot + Vaadin
- WebSockets (servidor Spring Boot + client React)
- Comunicació en temps real
- Temes complementaris (FCOO03 – inserció laboral, sensibilització…)
- Projectes finals i preparació professional

Els estudiants construeixen funcionalitats més complexes i experimenten amb comunicació bidireccional (WebSockets).

## Competències i Resultats

Al final del curs, els participants adquireixen:

- **Backend**: Domini de Spring Boot + JPA, modelatge relacional, disseny d’arquitectura per capes i proves
- **Frontend**: Coneixements de Vaadin i integració full-stack
- **Arquitectura**: Comprensió de DDD, acoblament, herència JPA i diverses arquitectures web
- **DevOps / Pràctiques**: Fluxos de treball amb Git, Maven, planificació Scrum, retrospectives i documentació
- **Mindset**: Responsabilitat de l’aprenentatge, gestió del temps i pensament crític

El curs equilibra la teoria (diagrames d’arquitectura, patrons i millors pràctiques) amb una gran quantitat de codi pràctic.

Els estudiants practiquen repetidament el flux:  
**requisits → UML → model → implementació → proves**

> **En resum**, l’IFCD0021-24 ofereix una experiència completa i centrada en projectes de Java FullStack que prepara els alumnes per a rols reals de desenvolupament. La complexitat progressiva de l’aplicació **Restaurant** esdevé un excel·lent projecte final que demostra el desenvolupament complet d’una aplicació en un stack tecnològic modern.
